## About

I build end-to-end data products: scrapers and ETL pipelines, the APIs behind them, the dashboards on top, and AI assistants that let people query their own data in plain language.

- **Backend & APIs:** Python and FastAPI, SQLAlchemy, scheduled jobs and data pipelines
- **Frontend:** React and Next.js with TypeScript and Tailwind CSS
- **Data:** SQL modelling, ETL, data quality and Power BI dashboards
- **AI:** LLM-powered assistants and agents, including local models with Ollama
- Software Engineering background. Everything I ship runs in Docker.
